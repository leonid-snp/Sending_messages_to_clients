# Sending messages to clients
Сервис рассылки уведомлений клиентам. 

## Описание
Сервис имеет возможность регистрации пользователя по E-mail, после регистрации администратор может дать права модератора этому пользователю. 
Пользователь имеет возможность создавать сообщения, клиентов, и рассылки, и редактировать только свои созданные, а модератор только просматриавать и включать или отключать рассылки, и банить пользователя. 


## 🚀 Стек
Python, Django, PostgreSQL, Docker, Docker-compose, HTML, CSS

## Перед началом убедитесь что у вас установлен redis-server
1. Выполните команду.
```
redis-cli ping
```
2. Если ответ `PONG` то переходите на следующий шаг, если нет то установите командой.
```
sudo apt install redis-server
```
3. Проверти что сервер активен и работает.
```
sudo systemctl status redis-server
```
4. Запустите сервер (при необходимости) и снова проверти статус.
```
sudo systemctl start redis-server
sudo systemctl status redis-server
```
5. Если все прошло успешно, приступайте к следуещему шагу, ечли нет проверти все ли выполнено верно

## Создайте базу данныйх Postgresql
1. Войдите как пользователь postgres
```
sudo -u postgres psql
```
2. Создайте базу данных `<name>`- имя базы данных
```
create database <name>;
```
3. Готово база данных создана, для выхода введите
```
\q
```

## Для работы переименуйте и заполните файл [.env.example](.env.example) в [.env](.env)
1. Копирование файла
```
cp .env.exampl .env
```
2. Заполнить файл с помощью редактора, можно использовать `vim, nvim, nano`.
```
#Пример на nvim

```
3. Функцианальные клавиши
- После открытияя редактора клавиша `i`- режим редактирования(можно печатать)
- Для сохранения файла нажать клавишу `ESC` и ввести команду `:wq`
- Для выхода без сохранения нажать клавишу `ESC` и ввести команду `:q!`

## django_setting
- SECRET_KEY= секретный ключ от приложения django
- DEBUG= (True or False)  Отладка (Вкл или Выккл) `default=True`

## bd_setting
- NAME= имя вашей БД
- USER_BD= пользователь БД
- PASSWORD= пароль от БД
- HOST= хост default=localhost
- PORT= порт default=5432

## # email_setting
- EMAIL_HOST=хост сервиса отправки писем
- EMAIL_PORT=порт
- EMAIL_USE_TLS=использовать безопасное соединение, булево значение
- EMAIL_USE_SSL=использовать защищенное соединение, булево значение
- EMAIL_HOST_USER=логин от сервиса отправки писем
- EMAIL_TO=почта с которой будут отправляться письма
- EMAIL_HOST_PASSWORD=пароль от приложения отправки писем

## # redis
- LOCATION=хост брокера редис `default=redis://127.0.0.1:6379/1`
